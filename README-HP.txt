CARA PASANG DARI HP ANDROID
1. Upload SEMUA file di folder ini ke GitHub Pages/hosting.
2. Buka alamat aplikasi.
3. Pada halaman "Hubungkan Supabase", kolom Project URL sudah terisi.
4. Tempel Publishable key yang tadi Anda salin dari Supabase.
5. Tekan "Hubungkan".
6. Login menggunakan username + password Owner/Karyawan.
7. Publishable key disimpan di browser perangkat tersebut. Tidak perlu mengedit index.html.

PENTING
- Gunakan hanya Publishable key (sb_publishable_...).
- JANGAN memasukkan Secret/service_role key.
- Jangan upload file ini hanya index.html; upload semua file.
- Database/RLS menggunakan struktur project Octari Laundry yang sudah Anda siapkan.
